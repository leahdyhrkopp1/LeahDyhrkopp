Cleaning and Exploring Bike Rental Data

Real data is messy. For this Python assignment, I was given two years of daily bike-share records with missing values and a few planted errors. My job was to find the problems, fix them and then dig into what actually makes people decide to ride.

The assignment

The dataset tracks a bike-share system day by day: the weather, the season, whether it was a working day and how many casual and registered riders took out a bike. This version had gaps in seven columns and some values that couldn’t possibly be right. Before any chart could be trusted, the data had to be inspected, cleaned and checked.

What I did

  1. Inspected the data

    I checked every column for missing values and odd codes. Along the way I found that the dataset’s documentation had the seasons wrong, and I used the dates to work out the correct labels.

  2. Cleaned the outliers

    I flagged columns with extreme kurtosis, removed values far outside the normal range (beyond 2.1 times the IQR) and filled those gaps with each column’s mean.

  3. Explored with charts

    I visualized how weather, season and the type of day shape ridership, then rebuilt those charts here so you can explore them yourself.

# Flag outliers beyond 2.1 × IQR and replace them with missing values
for col in cont_cols:
    q1 = df[col].quantile(0.25)
    q3 = df[col].quantile(0.75)
    iqr = q3 - q1
    lower = q1 - 2.1 * iqr
    upper = q3 + 2.1 * iqr
    is_outlier = (df[col] < lower) | (df[col] > upper)
    if is_outlier.sum() > 0:
        df.loc[is_outlier, col] = np.nan
        outlier_counts[col] = int(is_outlier.sum())

# Fill only the columns that had outliers, using each column's new mean
for col in outlier_counts:
    df[col] = df[col].fillna(df[col].mean())

What I found
  • 01

    A few bad values can distort everything. Six impossible temperatures pushed the column’s kurtosis to 162. After cleaning, it dropped to −1.06, a realistic spread with no extreme values.

  • 02

    Don’t trust the documentation blindly. The dataset’s notes said season code 1 meant spring, but the dates showed it covers December 21 to March 20. Code 1 is actually winter.

  • 03

    Weather drives ridership. Clear days account for 68% of all rentals. Light rain or snow days make up just 1%, across only 21 days.

  • 04

    Season matters too. A typical winter day had about 2,200 rentals, compared with about 5,300 on a typical summer day.

  • 05

    Two kinds of riders. Registered riders averaged 3,969 rentals on working days and 2,971 on days off. Casual riders did the opposite, doubling from 609 to 1,225 on non-working days.

What I learned

Cleaning came first, and it mattered more than any chart. Kurtosis worked like a smoke alarm, pointing me straight to the column with problems before I ever plotted it. Checking the season codes against the actual dates taught me to verify what a dataset claims instead of taking it at face value.

It also showed me why writing analysis as code matters. Anyone can rerun my notebook and get the same answer, which is a big part of what makes the results trustworthy.
